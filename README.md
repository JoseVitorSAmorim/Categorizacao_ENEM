# Categorizacao_ENEM
Extração do conteúdo das questões da segunda prova ENEM de 2012, caderno 5 por OCR
## Requisitos
- Python3
- Pdf2image
- pytesseract
- tesseract
- API Gemini 2.5 Flash

## Ativando ambiente virtual
### Linux
```
python3 -m venv venv  
source venv/bin/activate  
```
### Windows
```
python -m venv venv
venv\Scripts\activate.ps1
```
